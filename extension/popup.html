Framegen 关闭
将鼠标悬停在视频上，Framegen 按钮会出现在视频左缘。

提示"No GPU adapter" / 无法启动

浏览器的 WebGPU 未开启。在 Chrome 中：

  1. 打开 chrome://settings/system
  2. 开启"使用图形加速（如可用）"
  3. 完全重启浏览器

仍然不行？请到 NVIDIA/AMD/Intel 官网更新显卡驱动——旧驱动会被浏览器列入黑名单。

双显卡（笔记本）

Windows 上浏览器常常跑在核显上——帧率几乎不会提升。

  1. Windows 设置 → 系统 → 屏幕 → 显示卡
  2. 添加浏览器 → 选择"高性能"
  3. 完全重启浏览器

检查方法：在"状态"标签中 GPU 一行应显示独立显卡。

系统要求

Windows 上的桌面版 Chrome 或 Edge 121+，或 Firefox 141+，以及大约 2016 年及以后的显卡。Safari 和手机不支持。

使用方法

悬停任意视频：补帧开关（FG）、画面和设置按钮会出现在视频左缘。 对比功能（原始/处理后的分屏视图）在完整设置页中。

不支持的情况

Netflix、Crunchyroll 等 DRM 站点——浏览器不会把它们的像素交给我们，这是平台限制。 在部分站点上，首次开启补帧时视频可能会重新加载几秒（CORS），这是正常现象。
